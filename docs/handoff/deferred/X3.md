# Deferred game tests: X3

Owner: work order X3-5 (T7). Everything here needs the real game, real saves or real logs and is UNVERIFIED until run
on the Stellaris PC. Runbook: [`../GAME_PC_AGENT.md`](../GAME_PC_AGENT.md). Results go in
[`../GAME_PC_RESULTS_TEMPLATE.md`](../GAME_PC_RESULTS_TEMPLATE.md).

Conventions: PowerShell, repo root as cwd, `$out` = your output folder (for example `C:\sae_out`). Inputs are
`SAE_GAME_*` env vars (see the runbook). Unset input = test skipped with reason `game input missing: <VAR>`; set
but wrong path = fail. Run everything at once with
`uv run python3 tools/game/run_deferred.py --out $out` (writes `$out\summary.md`, `$out\inputs.json`, and the
private `$out\private\`). Args after `--` go to pytest, e.g. `-- tests/game/test_saves.py::test_parse_real_saves`.

Note F3/F4: F4 (code boundary) is game-free and green in CI; F3 (profile on real data) is X4 / V-1 work. Nothing
is claimed for them here.

Record rule for every entry: one row in `GAME_PC_RESULTS_TEMPLATE.md` (result, evidence file, notes) plus the
matching line in `$out\summary.md`. Never paste raw log lines or save content.
