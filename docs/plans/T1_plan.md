## 3. Checker (`uv run python3 mod/sae_bridge/tools/check_mod.py`; exit 0 = pass)

1. Braces balance per `.txt`/`.mod` file (ignore `#` comments and `"…"` strings); no tabs-vs-BOM issues;
   localisation file starts with UTF-8 BOM and has `l_english:`.
2. Every `log = "…"` template: render `[…]` tokens with sample values (date token → `2231.04.01`,
   `GetName` → `Kel | Name`, numeric vars → sample ints/decimals) and parse with
   `sae.contracts.c1_log.parse_log_line`; record type and **exact key set** must match the SEMANTICS §3/§4/§6/§7
   expectation; all 8 mod (status, code) pairs present exactly once; HELLO `mod=` equals descriptor version.
3. C2 variables: the set of `sae_p_*` + `sae_seq_pending` read by script == C2 country-line order list
   (`c2_ini._COUNTRY_ORDER`), and knob vars read == {`sae_emit_period`, `sae_quiet`}; both directions.
4. UNVERIFIED: every tag id ∈ README §5 registry ∪ ids PROPOSED in `contracts/proposals/006-T1-*`; every
   M0 id ∈ {M0-1..M0-14, M1-P, R-x}; every **risky token** (table in checker: `log =`, `is_multiplayer`,
   `global_event_country`, `modulo_variable`, `prev.`, `has_communications`, `add_opinion_modifier`,
   `trigger:`, `on_monthly_pulse`, `on_game_start`, `is_country_type`, `ai_budget` entries, `GetName`, date
   token, …) has a tag on its own line or the comment line directly above; `UNVERIFIED.md` equals the
   generated table (stale → fail; `--write-unverified` regenerates); every tag carries a non-empty
   fallback text (tag format `# UNVERIFIED(A-xx, M0-y): <claim> | fallback: <text>`).
   Templates may contain only these bracket tokens: the single date token, `[This.GetName]`,
   `[This.sae_*]`; anything else fails.
5. Cross refs: every `id = sae.N` fired/referenced is defined; every `sae_reason_<x>` loc key exists for each
   `ReasonKey`; every flag family member (`sae_econ_<plan>` etc.) matches C3 enums.

Tests: `uv run pytest mod/sae_bridge/tests -q` (not in default `testpaths = ["tests"]`, so repo-wide
`uv run pytest -x -q` is unaffected — stated in status). Lint: `uv run ruff check mod/sae_bridge`,
`uv run mypy --strict mod/sae_bridge/tools`.
