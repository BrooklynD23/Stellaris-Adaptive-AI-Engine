| Strategy (counter to) | econ | posture → target | reason_key (flavour text) |
|---|---|---|---|
| `outscale_siege` (turtle) | military | offensive → player | `turtle_siege` |
| `early_punish` (tech_rush) | military | offensive → player | `tech_rush_punish` |
| `hold_counterpunch` (early_aggression) | military | defensive → player | `aggression_hold` |
| `baseline` (balanced / below threshold) | balanced | deterrent → player | `baseline` |

The two differed only in the dropped hull mix (siege: cruiser 70 / battleship 80 / corvette 20; punish:
destroyer 70 / corvette 60). They now write identical C2 values (`econ`, `mil`, `mil_target`); the only
difference is `sae_p_reason`, i.e. which pre-authored flavour event the player sees. Switching between
them still opens a new 24-month window and an `outcome`, but changes no AI behaviour. Maintainer decision
(2026-10-19): keep both distinct in v0 (identical game values, different `sae_p_reason`); the split returns
with the hull mix after M0-7 (A-22). Implemented as is.
