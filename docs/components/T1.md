# Component: `sae_bridge` mod (T1)

Stellaris 4.4 Clausewitz mod, version 0.1.0. It produces C1 `SAE|v1|` log lines, consumes C2 `sae_in.ini`
staging (applied monthly), and exposes the C7 §6 knobs. Normative behaviour: `mod/sae_bridge/SEMANTICS.md`.
Nothing has run in the game: every game construct is UNVERIFIED (see `mod/sae_bridge/UNVERIFIED.md`).

## Layout
| Path | Role |
|---|---|
| `descriptor.mod` | name, version 0.1.0, `supported_version="v4.4.*"` |
| `common/on_actions/sae_on_actions.txt` | `on_game_start` → `sae.3` (HELLO); `on_monthly_pulse` → `sae.0` |

| `common/opinion_modifiers/sae_opinion_modifiers.txt` | `sae_posture_*` (3), `sae_stance_*` (4) |
| `events/sae_bridge_events.txt` | `sae.0` monthly driver, `sae.1`/`sae.2` console test hooks, `sae.3` HELLO, `sae.10` flavour popup |

| `tools/check_mod.py` | static checker (stdlib + `sae.contracts`) |
| `tests/test_check_mod.py` | checker tests (outside default `testpaths`) |

## Monthly order (`sae.0`)
1. Initialise (and HELLO) if needed.
2. `m += 1`.
3. Read knobs from the player.
4. Assign sids.
5. Mark managed AIs.
6. Print HB.
7. Apply staged batches and print ACKs.
8. Print the staggered SNAP/PLYR records (skipped when `sae_quiet = 1`).

The full rules are in SEMANTICS.md §4.

## Checks
```
uv run python3 mod/sae_bridge/tools/check_mod.py [--write-unverified]
uv run pytest mod/sae_bridge/tests -q
uv run ruff check mod/sae_bridge && uv run mypy --strict mod/sae_bridge/tools
```
The checker covers six areas:
- brace balance
- the BOM and ASCII rules
- every `log` template, rendered in plain and `.000` forms, parsed with `parse_log_line`, with exact key sets and all 8 ACK pairs
- the C2 variable set in both directions, plus the C3 enum families and loc keys
- event ids and calls to scripted effects or triggers (undefined or duplicate)
- UNVERIFIED tag format, registry ids and M0 ids, risky-token coverage by id, and freshness of `UNVERIFIED.md`

## Install (manual, M0 only)
Copy `mod/sae_bridge/` into the Stellaris user `mod/` folder with a matching `.mod` launcher file. Only the
maintainer does this, during M0.
