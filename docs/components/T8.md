## `sae m0` (src/sae/m0)

| Module | Role |
|---|---|
| `checks.py` | registry of 17 checks (M0-1..M0-14, M1-P, R-3, R-5): tier, A-ids, manual steps, pass rule, fallback; `GO_RULE` |
| `evidence.py` | read-only analyzers: StarNet hook grep, `error.log`, `game.log` (C1 parser, session-aware HB duplicates, streamed), ACK match, `sae-parse` timing (warm second run) with C4 validation |
| `tail.py` | M0-4 timestamping tailer (reuses T2 `LogTailer`), batching heuristic, Ctrl+C keeps the verdict |
| `results.py` | `m0_results/<id>.json` (`auto` + `manual`, manual wins), `env.json`, `m0_results.md`, go/no-go verdict |
| `cli.py` | `sae m0 list\|steps\|init\|stage\|check\|tail\|record\|summary`; global `--results`, `--user-dir`, `--game-log`, `--parser-exe` |

Safety: no command launches the game or writes under the Stellaris user folder; `--results` inside it (or under
`steamapps`) exits 2. Files the game needs (`sae_bridge.mod`, `sae_in.ini`) go to `<results>/stage/` and the
maintainer copies them. Only subprocess: `sae-parse parse --save` (fixed argv). Tests snapshot a fake user folder
across every command and scan the AST for process-launch calls.

Exit codes: 0 ok, 1 OS error, 2 usage/unsafe results folder.
