Paths: `src/sae/adapters/**`, tests in `tests/unit/t2/`. Plan: `docs/plans/T2_plan.md` (v2). Contracts: C1, C2 v1.1,

## Data flow

```text
game.log ─► LogTailer (bytes, split on \n, head + tail fingerprint) ─► parse_lines (C1) ─► Assembler
autosaves ─► SaveWatcher (8 s monotonic stability) ─► SaveParser (daemon's, governed) ─► Assembler.on_parse
Assembler ─► IntentAck (acks()), Observation (observations(), fog-legal), GodObservation ─► GodSink only
emit(IntentBatch) ─► compile_batch + render_ini (C3/C2) ─► IniWriter (tmp + fsync + replace, 0.1/0.2/0.4 s retry)
```

## Rules worth knowing

1. Epoch: +1 on HELLO or HB date regression, at most +1 per observation; first HB without HELLO opens the session
   at the current epoch. A new epoch drops cached SNAPs and the old save; a parse started in an older epoch is dropped.
2. Ordering: a pulse's ACKs are handed to T4's ack feeder before that pulse's observation (per-item `sleep(0)` handoff).
3. Writes are refused while the latest HELLO said `mp=1` (`error="multiplayer"`, C6 §1.6) and while `schema ≠ 1`.
4. Replay/synth determinism relies on proposal 011 (consumer handles an observation before pulling the next); the
   interim is a fixed 8-step handoff and a synchronous scratch write.
5. Recording (`record_dir`) is normalised text (LF, U+FFFD), `game.log.ts` = `<byte_offset> <monotonic_ns>` per poll,
   saves at `saves/<offset:012d>-<name>`.
