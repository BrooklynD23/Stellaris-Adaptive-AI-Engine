# T4 — Engine core and daemon loop

Paths: `src/sae/core/**`, `src/sae/daemon/**`, tests in `tests/unit/t4/`. Plan: `docs/plans/T4_plan.md`.

## Data flow (one game month)

```text
adapter.observations() ─► daemon queue ─► core.engine.on_observation
   features.extract (in-contact LegalViews only, evidence once per new legal_as_of)
   belief.update   (fixed-share ρ on evidence ticks, clipped centred log-lik, weight min(1,k/12))
   strategy.select (forced > 24-month commitment > COUNTER_TABLE / baseline; static safety floor)
   expansion.desired_intents (desired-state rule, in-contact managed AIs only)
   validator.validate (C3 §4 order) ─► IntentBatch ─► adapter.emit ─► engine.on_emitted
adapter.acks() ─► engine.on_ack (lifecycle: APPLIED/…/SUPERSEDED/LOST, one re-emit, ack_alarm)
every draft ─► BusSink.emit (T6 writer stamps the C5 envelope)
```

## Modules

| Module | Role |
|---|---|
| `core/dates.py` | month index ↔ GameDate |
| `core/features.py` | 6 fog-legal features (`first_war_month` report-only; `at_war` drives belief), `FeatureMemory`, session reset |
| `core/belief.py` | `LikelihoodModel` (HYP defaults, M2 calibrates), forgetful Bayes, diagnostic `change_score` (never read back) |
| `core/strategy.py` | commitment windows, C9 force/clear, safety floor |
| `core/expansion.py` | C3 v1.1 §6 templates → econ + posture intents (fleet bias dropped) |
| `core/validator.py` | C3 §4 rules |
| `core/lifecycle.py` | seq allocator + floor rule, ack tracker |
| `core/engine.py`, `engine_tick.py`, `state.py`, `outcome.py` | pure month step, `EngineState` (= `state.json`), outcome reward (HYP) |
| `daemon/ports.py` | T4-internal ports: `BusSink` (extends C6 `GodSink`), `ControlInbox`, `DaemonDeps` |
| `daemon/saveparser.py` | Governor-gated C6 `SaveParser` (every-n, H2 window, kill, exit-6 retry cap, C4 §2 classification) |
| `daemon/loop.py`, `control.py`, `statefile.py` | `run_engine`, C9 application, atomic `state.json`, re-exec guard |
| `daemon/cli.py`, `runs.py`, `runs_dir.py`, `wiring.py` | `sae daemon`, CURRENT lock, composition root (only place importing other teams, lazily) |

## Entry points
