## Governor (`governor/core.py`, pure, no I/O)

- Time comes only from `SensorSample.t_mono_s`; dt < 0 or > 60 s counts as 0 for accumulators.
- State: CLOSED when the game is absent or minimised ≥ 10 min, else PLAYING. PAUSED is cut:
  `pause_detection=true` behaves as PLAYING (UNVERIFIED A-25 until M1-P).
- Level = max(pressure, `min_level`), or `forced_level`; S while suspended. RAM and faults escalate on the
  same poll; spm only H0→H1, rate-limited; worker `budget_breach` → ≥ H2 (trigger `budget_breach`). Read-only `spm_med6` / `spm_med24` properties feed the C5 monthly metrics.
- Sustained H2 counts only months with an H2 trigger active. De-escalation is one level after 6 clean months.
- A game-date jump (`months > spm_short_months` in one sample) is a discontinuity, not play time (008 §8).
  CLOSED month length is floored at 5 × poll_s.
- `kill_worker` and `knob_request` fire on one poll at the pressure-level edge; they are latched while
  suspended and emitted on the first poll after resume.

## Sensors (`platform/sensors.py`)

psutil available RAM (probed at construction; later failures return the last good value). Faults: Linux
`/proc/vmstat` `pgmajfault` Δ/Δt, Windows PDH `\Memory\Pages Input/sec` (UNVERIFIED A-26). The game is found
by name (`stellaris`, `stellaris.exe`), the pid is cached with a reuse check, it rescans at most every 10 s,
and only read-only calls touch it. Minimised time is Windows only. `sample()` never raises; NaN/inf → None.

## Platform (`platform/spawn.py`, `_win32.py`)

| | Linux | Windows (not executed in CI on this machine) |
|---|---|---|
| Daemon | `setpriority(PRIO_PROCESS, 0, ≥10)` | BELOW_NORMAL + EcoQoS on `GetCurrentProcess()` |
| Worker priority | `ionice -c3 -t`, `SCHED_IDLE` in `preexec_fn` | `IDLE_PRIORITY_CLASS \| CREATE_NO_WINDOW` |
| Memory cap | `systemd-run --user --scope -p MemoryMax -p MemorySwapMax=0` if the probe passes and the memory controller is delegated; else `RLIMIT_AS` (clamped to hard), `MALLOC_ARENA_MAX=2` | Job `PROCESS_MEMORY` + `KILL_ON_JOB_CLOSE` (A-27 UNVERIFIED), assigned right after spawn |
| Output | stdout capped at `MAX_STDOUT_BYTES` (kill past it), stderr capped at 64 KiB | same |

Safety: no function takes a PID. `tests/unit/t5/test_no_foreign_pid.py` records every pid used for a control
call and every attribute touched on the game process, and scans the source for affinity, priority, signal
and process-open calls.
