### Added (T3 Parser)
- `sae-parse` Rust CLI implementing C4 v1: `parse`, `fixture`, `--version`; section-selective extraction; C4 §3 legal/god/self-state features; self-measured `cost`; Windows `--background` mode.
- Fixture renderer and 9 fixtures under `parser/fixtures/` (4 archetypes, observer mode, no contact, two-front war, plain text, pathological 2×).
- Hardening caps (zip size/entries, gamestate size, span size, entry count, name length) mapped to clean exit codes; fuzz, golden and memory-stress tests.
- Contract proposals 001–003 (T3).
- Proposal 007: seq and `LegalView` counts above 1,000,000 now exit 5 `parse` (never clamped); fixture specs with seq above the cap exit 2.
- Proposal 030: Windows `cost.rss_peak_bytes` now reports peak commit (`PeakPagefileUsage`) instead of `PeakWorkingSetSize`, which `--background` caps at ~32 MiB; field name unchanged. Parser crate bumped 0.1.0 -> 0.1.1 to mark the change: Windows values from 0.1.0 are working set, do not compare across the boundary.
- Parser 0.1.2: meta-only fast path (`--sections meta` skips the gamestate inflate when the zip meta has `date` and `version`; gamestate presence still checked; proposal 032, C4 v1.2, A-47 UNVERIFIED). Synthetic 200 MiB save: 0.31 s / 213 MB full vs 0.0002 s / 3.7 MB meta-only (debug build). Tests force the full path with a debug-build-only env var `SAE_PARSE_FORCE_FULL`; release builds ignore it.
- Parser 0.1.3 (Wave 1.5 WO-B, proposal 038, C4 v1.3): emits `LegalView.player_offensive_war_count` (player-led wars with no SAE-tagged country among the attackers; null when not in contact; A-55 UNVERIFIED); fixtures `war_ai_attacker` and `war_ai_led_player_coattacker`; test pins `systems_owned` equal across observers.
